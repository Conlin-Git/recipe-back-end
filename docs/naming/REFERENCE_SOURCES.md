# 命名 Agent 数据源清单

## 已纳入仓库的规范资料

- `sources/GF3002-1999-GB13000.1-stroke-order.pdf`：教育部公开的 GB13000.1 汉字笔顺资料。
- `sources/GF3001-1997-components.md`：部件规范入口和下载地址记录。
- `sources/SOURCE_MANIFEST.json`：来源 URL、版本、下载时间、SHA-256 和使用说明。

## 四类数据的实现边界

### 1. 命理规则库

当前运行规则为 `bazi-bootstrap-v2`：使用 `lunar-python==1.4.8` 计算节气四柱，再把年、月、日、时柱的五行做数量平衡启发式，并输出月令、日主强弱粗粒度标签和生克关系依据。代码不会把“日主强弱、格局、喜用神”伪装成统一定论。

生产版需要采购或取得授权的传统命理书籍，再由命理顾问按流派标注：书名、版本、章节、原文摘录、适用条件、反例和 `rule_id`。每个流派单独发布 `ruleset_version`，禁止跨流派静默合并。

### 2. 汉字五行映射表

`app/naming/data/characters.json` 是明确标注为 `bootstrap-cultural-rules-v1` 的种子数据，字段包含字、五行、字义和来源；它不是“汉字客观五行真值”。正式数据需增加 `school`、`edition`、`annotator` 和冲突记录，同一字的不同流派并列返回。

### 3. 康熙笔画表

`app/naming/data/kangxi_strokes.json` 独立于现代规范字形数据，当前明确标注为 `kangxi-bootstrap-v1`。GF 3002-1999 PDF 只作为现代字形/笔顺参考，绝不拿现代笔画替代康熙笔画。正式版应采购或取得《康熙字典》授权数据，保留繁简映射、异体字和版本。

### 4. 姓名负面风险库

`app/naming/data/risk_terms.json` 是 `risk-bootstrap-v1` 人工审核种子库，支持负面词、粗俗词、文化联想、重复字和数据覆盖风险。生产版应接入经授权的现代语料，按普通话/方言、地区、网络语义、用途分层，并保留人工审核人、日期、证据句和严重度。

## 运行时参考来源

1. 中国科学院紫金山天文台历书查询和历书科普说明：公历、农历、节气、干支边界。
2. 教育部《通用规范汉字表》：候选字范围和现代姓名用字规范。
3. Unicode Unihan：字符读音、定义、异体字和基础 Unicode 属性。
4. 厦门大学国家语言资源监测与研究中心：现代汉语语料和词义资源。
5. 中国哲学书电子化计划：古籍原文和名字出处检索。
6. 公安部户口居民身份证管理规范：姓名登记用字和公序良俗约束。

## 版权和质量边界

- 规范文件保留原始来源、版本和哈希，不把搜索引擎结果当作事实库。
- 《新华字典》《现代汉语词典》《康熙字典》等商业或受版权保护的完整内容不得直接抓取进仓库；需要采购授权或只保存经许可的结构化字段。
- 命理古籍可以作为传统文化依据，但不同流派规则必须分别版本化，不能声称存在统一科学结论。
- `app/naming/data/characters.json`、`kangxi_strokes.json`、`risk_terms.json` 都是可运行的 bootstrap 数据，正式上线前必须由语言和命理顾问审核扩充；接口会把版本写入报告和 MySQL 快照。
