# 命理命名 Agent 持久化任务

更新时间：2026-10-31

## 目标

在现有菜谱、开发、闲聊 Agent 之外，增加一个可审计、可复现的命理命名 Agent，支持：

- 根据出生信息、姓氏和命名约束生成网名、笔名、人名候选；
- 对给定姓名进行八字适配度和语言文化风险评分；
- 同一用户、同一输入、同一规则版本返回同一结果；
- 不同用户可以在相同八字基础上获得不同候选排序；
- 输出逐项分数、规则编号和参考出处，形成论文式报告；
- 规则、知识库和历法版本可追踪，历史结果不可被新规则覆盖。

## 验收约束

1. 计算核心不得依赖大模型；大模型只负责解释和追问补全。
2. 查询时间只用于审计，不参与结果指纹和排序。
3. 规则冲突必须展示流派和版本，不能静默合并。
4. 报告必须区分传统命理依据、语言学依据和产品启发式评分。
5. 该功能只能表述为传统文化/语言文化分析，不宣称科学预测人生结果。
