# 院校专业组与专业录取数据采集方案

更新时间：2026-10-31

## 结论

`gaokao_admissions` 不能靠一个全国统一接口补齐。官方数据有两个不同层级：

1. **院校专业组投档数据**：省级招办在录取结束后公布，通常包含院校代码、专业组代码、批次、科类、投档最低分，有些省还公布最低位次、计划数、投档数和同分排序项。
2. **专业录取数据**：高校将考生投档后按招生章程分配到专业，最低分、平均分、最高分和专业录取位次通常只在省级历史数据系统、高考指南或高校招生网中提供。

这两层不能混成同一条“分数线”。系统必须保留 `record_kind`（`group_admit`、`group投档`、`major_admit`）和原始来源，否则会把院校专业组投档线错误展示成专业录取线。

## 官方来源优先级

### P0：省级招办历史录取系统或官方高考指南

这是专业级数据的首选来源。部分省份已经提供可查询的结构化历史数据：

- 安徽省招生考试院的历史数据查询覆盖 2021—2025 年，并按批次、学校、专业组/专业给出最低、最高、平均分和排名。
- 江西省教育考试院公告说明，历史查询提供 2024—2025 年在赣招生高校各专业的最低分、排名和人数。
- 广西招生考试院的《高考指南》和“阳光志愿”系统同时提供上一年度院校专业组及专业的计划、投档/录取人数、最高/平均/最低分和最低排位。
- 甘肃志愿辅助系统的招生计划详情关联上一年度专业组和专业的最低、最高、平均分、最低位次、计划数等字段。

这类系统若公开导出 CSV/XLSX/JSON，直接保存原文件并导入；只有查询页面时，使用公开接口逐页抓取，保存请求参数和响应摘要。不得使用考生账号、验证码绕过或查询个人录取结果。

### P0：省级招办公布的投档最低分表

用于补齐院校专业组层级，兼容本科和高职专科：

- 省教育考试院官网发布的 HTML、PDF、XLSX；
- 教育部阳光高考平台转载的省级官方文件；
- 省级“高考录取结果/投档线”公告及附件。

阳光高考已有公开样例：广西 2025 年高职高专普通批表包含院校代码、院校名称、专业组、投档最低分和备注；山西 2025 年院校专业组投档最低分文件包含批次、院校、科类、专业组和最低分；江苏 2025 年专科批表还包含同分排序项。空白最低分必须保留为“未投档”，不能转成 0。

### P1：高校本科招生网/招生办公室

用于补齐省级系统没有公开的专业录取数据。按高校、年份、省份、批次、科类抓取“分省分专业录取分数统计”页面或 PDF，重点解析：

```text
院校代码、院校名称、年份、省份、批次、科类、专业组代码、专业组名称、
专业代码、专业名称、选科要求、计划数、录取数、最低分、最低位次、平均分、最高分、备注
```

高校页面只作为该校该省数据的权威来源。不能用高校全国最低分代替某省分专业最低分；不能把招生计划表当成录取结果表。

### P2：教育部阳光高考/阳光志愿

阳光高考可作为官方入口、院校/专业主数据和省级文件镜像；“阳光志愿”是教育部面向考生提供的志愿服务系统。若页面仅展示结果而没有公开下载和可追溯来源，保留为检索入口，不直接当作正式落库证据。

### 禁止来源

第三方聚合站、自媒体表格、搜索摘要、考生个人截图只能用于发现线索，不能进入 `validation_status=verified` 的正式数据。若必须临时展示，单独放入 `unverified` 数据集并在接口层禁止推荐。

## 采集架构

```text
官方入口登记
  -> 原始文件/响应归档（不可变）
  -> source manifest + SHA-256
  -> 解析 staging 表
  -> 口径/字段/重复/范围校验
  -> 人工抽样复核原文
  -> verified admissions 正式表
  -> 位次匹配与冲稳保计算
```

建议增加以下落地目录：

```text
data/gaokao/<year>/<province>/raw/<source-key>/*
data/gaokao/<year>/<province>/staging/*.jsonl
data/gaokao/<year>/<province>/verified/*.csv
```

每个来源必须记录：发布机构、原始 URL、抓取时间、发布时间、年份、省份、批次、科类、文件名、HTTP 响应摘要、SHA-256、解析行数、授权/使用说明、人工复核人和复核时间。

## 需要补充的数据库字段

当前 `gaokao_admissions` 已能保存基本院校/专业/分数/位次，但还不能完整表达所有官方表。下一步迁移增加：

- `record_kind`：`group投档`、`group_admit`、`major_admit`；
- `admission_count`、`投档_count`、`tie_breaker`；
- `plan_type`：普通、专项、定向、预科、合作办学等；
- `source_locator`：页码、表格名、行号或公开查询参数；
- `raw_record_hash`：原始行哈希，支持重复导入审计；
- `verification_status`、`verified_at`、`verification_note`；
- `admission_status`：正常录取、未投档、缺额、征集志愿等。

现有 `min_score`、`min_rank`、`avg_score`、`max_score`、`plan_count` 保留；专业录取没有位次时必须保持 `NULL`，不能根据分数和一分一段表跨口径推算成“专业最低位次”。

## 解析器与校验器

按来源格式实现适配器，不写一个“万能正则”：

1. `chsi_article`：解析阳光高考 HTML 表格和附件链接，保留文章 URL、附件 URL 和文章发布日期。
2. `province_table`：解析省考试院 HTML/PDF/XLSX，按省份配置批次、科类、同分排序列和专业组字段。
3. `province_history_api`：只调用公开历史查询接口，缓存请求参数和响应，遇到登录、验证码或个人信息字段立即停止。
4. `university_admission`：按高校域名配置 HTML/PDF 模板；无法稳定解析的页面进入人工待处理队列，不做猜测。

每批导入必须通过：

- 主键无重复：省份、年份、批次、科类、院校代码、专业组代码、专业代码、记录类型；
- 分数、位次、计划数和人数范围检查；
- 空值语义检查：未投档和无位次不可转成 0；
- 院校代码与院校名称一致性检查；
- 专业组内专业必须来自同一计划文件或同一来源；
- 解析行数与原文页数/总数抽样核对；
- 原始文件 SHA-256 与来源记录一致。

如果官方站点要求验证码、考生登录或临时限制自动请求，不绕过访问控制。可在官方页面手工下载公开文件，再挂载到同一个采集 run：

```bash
.venv/bin/python scripts/attach_gaokao_artifact.py \
  --manifest data/gaokao/admission_sources.json \
  --run-id 2026-admission-official-v2 \
  --source-id chsi-2025-guangxi-vocational-history-physical \
  --file /path/to/official.xlsx

.venv/bin/python scripts/stage_gaokao_admissions.py \
  --manifest data/gaokao/admission_sources.json \
  --run-id 2026-admission-official-v2
```

挂载动作仍会计算 SHA-256，原始文件保存在 `raw/`，网络失败和人工挂载都能在同一个 `state.json` 中回溯。

## 推荐的实施顺序

1. 先采集 31 省 2025/2026 年本科、专科普通类院校专业组投档表，快速让 `group投档` 有覆盖。
2. 并行接入已公开历史查询系统，优先安徽、江西、广西、甘肃等已有专业级字段的省份。
3. 对剩余省份建立高校招生网采集清单，按招生规模从高到低补齐 `major_admit`；每校每省每年单独留来源。
4. 导入当年招生计划和选科要求，解决专业改名、专业组变化和计划变动造成的错配。
5. 只有当同一省份、年份、批次、科类具备可核验的组级或专业级记录时，指南才生成对应层级结果；缺少专业级记录时明确显示“仅有专业组投档数据”。

## 产品展示规则

- 结果卡片显示“数据层级”：院校专业组投档线 / 专业录取线。
- 同时显示分数、位次、计划数、录取数、录取类型和来源页码。
- 专业线与组投档线分开展示，不做隐式替换。
- 历年数据跨年只比较同省、同批次、同科类、同记录类型；专业组代码变化时必须标记“口径变化”。
- 没有正式 verified 数据时返回数据不足，不生成冲、稳、保院校推荐。

## 本科优先落地记录

本轮已先落地广东省教育考试院 2025 年本科普通类正式投档表：历史类 1,637 条、物理类 3,503 条，共 5,140 条院校专业组记录，最低分和最低排位均来自官方 PDF。PDF 原件、解析结果、复核状态和 SHA-256 在 `data/gaokao/collection_runs/2025-admission-undergraduate-official-v1/`，部署 seed 在 `data/gaokao/seeds/`。PDF 解析器使用 `pdftotext -raw`，解析不完整会整批失败，不会静默漏行。

2026 年广西高职高专 1,564 条记录仍作为独立采集批次保留；它们不冒充本科数据，也不会在本科批次查询中混入。后续采集按本科普通批、提前批本科和本科特殊类型的官方表优先，再补专业录取层级。
