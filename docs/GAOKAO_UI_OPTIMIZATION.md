# 高考志愿指南三阶段优化

更新时间：2026-11-01

## 已实现

- 输入区域拆成成绩口径、比较范围、补充筛选三个区块，并在页面顶部明确当前只覆盖四川、广东、上海院校所在地。
- 推荐结果改为摘要统计 + 可筛选表格，默认按最低投档/录取分从高到低；支持最低位次和安全余量排序。
- 位次落后历史线时直接判为“冲”，避免出现“未达到 + 稳”；没有可比最低位次的记录标记为“数据不足”，但仍保留在结果表中。
- 推荐结果读取参考年份前最多五年的已核验记录，显示历史年份、数据层级和数据质量（官方位次、换算位次、仅最低分）。
- 新增 `POST /api/v1/gaokao/catalog` 本科院校目录接口和 `GET /api/v1/gaokao/coverage` 覆盖范围接口，前端提供“本科院校总表”视图和分页筛选。

## 数据边界

院校总表当前由 `gaokao_admissions` 中已核验的官方录取记录聚合生成，不会把没有公开来源的院校补写成有分数的记录。四川 2026 本科全量投档表仍未公开归档，页面会继续展示“非全量”提示；后续取得合法可复核的官方院校目录或全量投档文件后，可在不改变页面契约的情况下补充导入。

## 接口变化

`POST /gaokao/guide` 新增 `history_years`、`sort_by` 入参，并返回 `summary`、`coverage`；推荐项新增 `comparison_rank` 和 `data_quality`。

`GET /gaokao/options` 返回 `coverage`；`POST /gaokao/catalog` 支持院校所在地、年份、科类、批次、关键词和分页；`GET /gaokao/coverage` 返回当前招生省份为四川时的院校所在地/年份记录量。
